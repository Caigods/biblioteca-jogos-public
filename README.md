# Biblioteca Jogos

Projeto organizado como monorepo, com back-end e front-end separados.

## Estrutura

```txt
biblioteca-jogos/
  backend/   API Spring Boot
  frontend/  Aplicacao React
```

## Back-end

O back-end atual esta em `backend/`.

```powershell
cd backend
.\mvnw spring-boot:run
```

## Front-end

O front-end React sera criado em `frontend/`.
